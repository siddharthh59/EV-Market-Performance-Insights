# EV Market Performance & Insights Platform

A full-stack Business Intelligence web application built with Python (Flask) and Tableau Public. It centralizes complex Electric Vehicle (EV) datasets into an interactive web portal, providing actionable insights for non-technical stakeholders.

## 🛠️ Tech Stack
*   **Backend:** Python, Flask
*   **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
*   **Data Preparation:** Pandas
*   **Data Visualization:** Tableau Public

## 🚀 Features
*   Fully responsive web interface.
*   Interactive Tableau Dashboard with dynamic filtering (by region, year, and powertrain).
*   Guided Tableau Story for chronological data narratives.
*   Clean, modern UI using the Bootstrap template.
